# 项目方向卡 — Sentinel Vault

## 一句话

监听 Sepolia 上 `MockOracle` 的 `PriceUpdated` 事件；当价格越过设定的止损 / 止盈带时，由 Lasna 上的 Reactive 合约回调 Sepolia 上的金库 `SentinelVault.execute()`，自动把金库中的资产退回给 depositor。

## 赛道

**2 — Set It and Forget It（个人自动化）**

说明：用户存入资产并设定价格带后「设好就忘」，无需 24 小时盯盘，触发时全链路自动执行平仓退款。
- 非赛道 1：不涉及 1 秒级延迟套利，对亚秒级反应无硬性要求。
- 非赛道 3：运行时无 AI 决策，仅用固定规则（价格带越线）做链上判定。

## 目标用户和真实场景

- **谁会用**：持有现货、想用止损 / 止盈保护仓位，但不愿或无法持续盯盘的个人用户。
- **现状怎么解决**：依赖中心化交易所的条件单（资产托管在交易所，存在宕机 / 下线 / 平台风险），或手动盯盘执行。
- **本方案的不同**：资产留在用户自己的链上金库，触发条件与执行都在链上可验证；回调经 `onlyCallbackSender` / `onlyServiceProvider` 鉴权，任意地址无法冒领。

## 最小 Demo（第 2 周结束前必须跑通的链路）

`MockOracle.setPrice`（Sepolia，发 `PriceUpdated`）→ `SentinelReactive.react`（Lasna，判定越线后 `requestCallback`）→ `SentinelVault.execute`（Sepolia，复核价格后退币给 owner）。

三笔真实交易已拿到，见 [README.md](../README.md) 与 `docs/submission.md`。
